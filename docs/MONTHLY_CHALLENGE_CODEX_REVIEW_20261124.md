## 本轮复验与修复

- 每个本地日历月只能创建一个实例；领取窗口边界、过期、换签、跳过、暂停、恢复和放弃均检查状态及资格。创建与状态事件在事务中写入，恢复或重复请求不会重新打开已消耗的领取资格。
- 接受时冻结模板版本、时区、截止时间、证据截止时间和奖励配置快照。生产默认没有已批准奖励，因此未配置时不能接受或发奖。
- 行动时间必须不晚于挑战截止；提交时间必须在实例冻结的证据截止时间内。里程碑必须属于该实例并遵循单次人工验收状态。证据摘要仅用于发现记录内容变化，不构成客观验收，也不宣称是附件正文哈希。
- 到期协调区分按时完成、证据补交期限及未完成状态；奖励、挑战状态、事件和 XP 台账在同一事务中提交，并通过奖励唯一关联和台账来源实现幂等。
- 成就条件现在读取已验收挑战、完成里程碑和有效奖励事实；月度结算后触发成就重算。挑战奖励沿用 XP 台账；娱乐账本未改。
- 增加前台和系统到期协调接线；备份恢复校验实例、里程碑、证据、事件、奖励与 XP 引用。无挑战数组的旧备份恢复为空挑战表；非空库往返测试检查了既有任务、睡眠和 XP 历史。
- 根据正式规格冻结首批模板，等待产品规则确认后再发布：目前模板未发布、阶段权重为空，挑战功能保持关闭。
