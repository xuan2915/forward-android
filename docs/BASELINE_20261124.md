# 向前开发基线（2026-11-24）

## 主线与项目身份

本私有仓库的开发主线为 **main**。它来自现有集成工作树 **feat/data-protection-complete**，保留代码提交链，并把当前未提交的成长底层实现整理为可复验基线。发布历史移除了本机 QA/截图/录屏/APK、含个人健康与任务记录的工作日志，以及个人邮箱元数据；原始工作树及其本地证据均留在本机，未被清理。

应用标识为 **com.focus.prototype**，当前版本 **0.10.10 / versionCode 37**，数据库版本 8。此基线纳入 XP 流水、等级曲线、成就配置/计算、备份接线及对应测试；它不包含月度挑战模块，也不包含月度挑战 UI 或新美术。

GROWTH_FOUNDATION_GEMINI_DELIVERY.md 记录了此前 Codex 的定向复验：11 个指定测试类，101 项、100 通过、0 失败、0 错误、1 项因未提供外部手机恢复 fixture 而按条件跳过；随后 :app:assembleDebug 成功。这些是该交付记录中的历史结果，本轮没有重跑测试或构建。
